示例文章:中文排版样式演示

2026 年 8 月 20 日

这篇文章演示了博客支持的全部排版元素。写新文章时,可以复制 template.html 后对照本文选用需要的元素。正文段落就像这样:字号 17px,行高 1.7,适合中文长文阅读。

二级标题:章节的划分

用 <h2> 划分文章的主要章节。文章页的一级标题只有开头一个,正文从二级标题开始用起。

三级标题:小节

更细的层次用 <h3>。一般到三级就够了,层次太深读者会迷路。

列表

无序列表适合并列的要点:

  • 第一个要点,简短有力;
  • 第二个要点,可以稍微长一点,长到需要换行也没问题,行距和缩进都已经处理好;
  • 第三个要点。

有序列表适合有先后顺序的步骤:

  1. 先做这一步;
  2. 再做这一步;
  3. 最后检查结果。

引用

好的排版是隐形的:读者注意不到它,只觉得读起来舒服。—— 某位排版设计师

代码

行内代码用 <code> 标签,比如 console.log()。整块代码用 <pre><code>:

// 一个简单的示例
function greet(name) {
  return '你好,' + name + '!';
}

console.log(greet('世界'));
